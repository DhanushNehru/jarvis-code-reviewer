# Enterprise Features

- **Automated Multi-Agent Review:** Get instant feedback from Security, Performance, and Architecture agents concurrently.
- **RAG-Powered Organizational Rules:** BigQuery integration ensures code adheres to your specific corporate guidelines.
- **Bring Your Own Key (BYOK):** Use your custom Vertex AI / Gemini API keys.
- **Leaderboard & Global Analytics:** Compare your code quality rating with engineers globally (Opt-in privacy).
- **Direct GitHub Repo Scanning:** Paste raw GitHub URLs instead of copying and pasting code manually.
- **Immersive UX:** Fully themed Light/Dark mode, Custom Scrollbars, and Text-to-Speech Voice Effects.
